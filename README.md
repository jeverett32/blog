# The John Everett Journal

A newspaper-style blog built with a New York Times aesthetic, featuring clean typography, elegant layouts, and a professional reading experience.

## 🎨 Design Philosophy

This blog is inspired by the timeless design of The New York Times, featuring:
- **Libre Baskerville** serif font for headlines and a traditional newspaper feel
- **Libre Franklin** sans-serif for body text and optimal readability
- Clean, minimalist layout with generous white space
- Drop cap on the first paragraph of each article
- Professional bylines and metadata presentation
- Responsive design that works beautifully on all devices

## ✍️ How to Add New Articles

### Method 1: Using the Admin Panel (Recommended)

1. Navigate to `/admin` on your site (e.g., `https://johneverettblog.netlify.app/admin`)
2. Log in with your Netlify Identity credentials
3. Click **"New Journal Articles"**
4. Fill in the article details:
   - **Article Title**: Your headline
   - **Publish Date**: When it should go live
   - **Featured Image**: Upload a high-quality image (1200x800px recommended)
   - **Read Time**: Estimate (e.g., "5 min read")
   - **Tags**: Add categories (max 5)
   - **Short Description**: 2-3 sentence summary for homepage
   - **Article Body**: Write your article in Markdown
5. Click **"Publish"** to save and deploy

### Method 2: Manual File Creation

1. Create a new `.md` file in the `posts/` directory with a URL-friendly slug (e.g., `my-new-article.md`)
2. Add frontmatter at the top:

```yaml
---
title: Your Article Title
date: 2025-12-08
thumbnail: /assets/uploads/image.jpg
readTime: 5 min read
tags:
  - Tutorial
  - AI
description: A brief description of your article that appears on the homepage.
---
```

3. Write your article content below the frontmatter using Markdown
4. Update `posts.json` with the article metadata (or let Netlify do this automatically)

## 🔄 How the Blog Updates

### Automatic Updates (Netlify)

When you publish through the admin panel:

1. **Content is saved**: Your article is committed to the `posts/` directory
2. **Build is triggered**: Netlify automatically rebuilds your site
3. **Site deploys**: Changes go live in ~1-2 minutes
4. **RSS updates**: The site automatically includes new articles

### Manual Updates

If you add articles manually:

1. Commit changes to your Git repository
2. Push to your `main` branch
3. Netlify detects the push and rebuilds automatically
4. Site updates within 1-2 minutes

## 📝 Markdown Formatting Guide

### Headers
```markdown
## Main Section Header
### Subsection Header
```

### Text Styling
```markdown
*italic text*
**bold text**
```

### Lists
```markdown
- Bullet point
- Another point

1. Numbered list
2. Second item
```

### Links
```markdown
[Link text](https://example.com)
```

### Images
```markdown
![Alt text](/assets/uploads/image.jpg)
```

### Code
````markdown
Inline `code` with backticks

```python
# Code block
def hello():
    print("Hello, World!")
```
````

### Blockquotes
```markdown
> This is a quoted section
```

## 🔧 Customization

### Change Colors
Edit the CSS variables in `index.html` and `post.html`:
```css
:root {
  --nyt-black: #121212;
  --nyt-gray: #333;
  --nyt-light-gray: #717171;
  --nyt-accent: #326891;
}
```

### Change Fonts
Replace the Google Fonts import in the `<head>` section of both HTML files.

### Modify Layout
The blog uses Tailwind CSS utility classes for layout. Edit the HTML structure and classes to customize.
